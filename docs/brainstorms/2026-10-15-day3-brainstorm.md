# Day 3 brainstorm: explicit assertion states

More positive wrappers alone would make 50 files, not a useful challenge set.
Use the existing five provisional mappings with affirmed, negated and uncertain
assertions. A closed sentence template makes the intended status unambiguous.

Choose an explicit-state builder, not an NLP classifier. Labels come from the
scenario definition, independently of any future auditor. Negation and uncertainty
are distinct states; neither is gold support. This is a synthetic benchmark rule,
not inpatient/outpatient or payer guidance. Mixed notes exercise condition-local
scope; entirely negative or uncertain notes test empty gold sets.

Keep the day-2 generator untouched. Add 37 unique scenarios in a separate pure API,
then store one schema-compatible file per case. No new code mappings or identifiers.
Clinical mapping verification and independent label review remain open milestones.
