# 30-day plan (each feature in a fresh session; tests frozen once written)

## Week 1 - Foundation and data
1. Repo, spec, rules, test scaffold (done at setup)
2. Synthetic note generator + schema (labelled synthetic)
3. Gold labels for ~50 synthetic cases
4. Error injector (5 error types)
5. Eval runner skeleton + metrics (precision/recall per error type)
6. Evaluation-label validation: manually review sample of gold labels, record agreement, fix labels BEFORE trusting scores
7. Week review, decision-log check

## Week 2 - Auditor core
8. Output schema + validators
9. Rule-based baseline auditor (keyword/negation)
10. LLM auditor v1 (single prompt, evidence quotes required)
11. Evidence-span verification (quote must exist in note)
12. Negation/uncertainty handling
13. Run evals, baseline vs LLM
14. Week review

## Week 3 - Agent and robustness
15. Tool: ICD code lookup (descriptions/hierarchy)
16. Agent loop with tools (retrieve, check specificity)
17. Missed-code detection
18. Upcoding detection
19. Failure analysis report
20. Cost/latency tracking
21. Week review

## Week 4 - Report, CPT, private track
22. Report generator (markdown/HTML)
23. CPT synthetic cases (v2 spec first)
24. CPT auditing
25. Private MIMIC track IF credentialed (separate private repo/env, zero-retention LLM only, nothing in this repo)
26. Regression suite + CI
27. Demo script and README results
28. Interview write-up (decisions, rejected options)
29. Polish, docs
30. Buffer / final release
