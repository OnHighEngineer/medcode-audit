breaks eval failures down by error type and stratum; the day-20 review

## Goal
Plan item 20: record cost and latency per model call at the transport
boundary. Wrap any transport in a decorator that times the call and
counts prompt/reply size (characters as the offline unit; no tokenizer
dependency), collects per-call records, and renders a deterministic
provisional summary (calls, total/mean latency, total characters in and
out). Wire it into an eval run so a review doc can compare auditors on
cost, not just detection.
